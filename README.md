# 接力卡 · 校园好物，继续发光

基于「接力卡 Agent 编排设计」的校园交易交互原型。视觉参考提供的校园市集照片，采用草绿色、紫色与奶油白。

## 本地运行

```sh
npm install
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

浏览器打开 http://localhost:4173/ 。构建命令为 `npm run build`，静态文件输出到 `dist/client`。

## 可体验的流程

- 分类、搜索、价格排序、免费接力、收藏与物品详情。
- 输入 `ITEM-0001` 查询物品，查看平台记录、上传记录与未知历史。
- 物品照片上传、手动填写描述、报价和领取地点。
- 可选历史凭证上传：填写凭证能确认的价格、时间与来源，明确标记 Uploaded Record。
- 物主确认后进入审核工作台；模拟工作人员通过或退回价格字段。
- 修改报价形成新版本，新版本通过前，市集继续展示此前获批版本。
- 成交需要分别勾选买家与卖家确认，平台计数才增加；上传历史不会计入平台次数。
- 已成交物品可以用同一 Item ID 再次接力，保留原有历史。
- 联系物主提供本地聊天演示，不发送外部消息。

## 边界

这是前端原型，不是已上线交易平台。商品、人物和交易记录为示例数据。未接入登录认证、后台权限、真实聊天、自动 OCR、支付或真实审核服务。工作人员按钮和双方成交勾选用于演示不同角色。

数据保存在当前浏览器 localStorage，不在不同浏览器间同步。上传图片会在本地缩小并压缩，不发送到服务器。清除该站点数据即可恢复示例市集。请勿用此原型存储唯一一份重要交易凭证。
