# 报价识别与参考价

## 已可使用

一句话输入即时显示识别到的报价，进入确认卡后自动带入。支持“我想卖10元”“我想卖１０元”“我想卖十元”“我想卖个10元”“报价10元”等表达。原价、被否定的报价、多种报价不自动当作当前报价，最终由物主核对。

确认卡增加“看看参考价”：从本站同类物品的正数挂牌价中去重比较，至少三条样本才展示中位数；少于三条仅展示样本。免费物品不参与有偿报价统计。目前网站是本地演示市集，因此全部注明“本站示例挂牌价”，不是实时市场价格，也不冒充平台成交价。

参考价不改动物主报价；点击“采用”才填入，且取消之前的提交确认，需要重新核对。只比较大致品类，不保证同型号、同成色，不做自动折旧或功能完好的推断。

## 联网能力：代码完成，尚未启用

`POST /price-reference` 接受 `{"name":"具体物品名称及型号"}`，返回 `samples / suggested / checkedAt`。

流程：Tavily 搜索公开报价页面 → Qwen 筛选可比较的二手样本 → 程序验证逐字引用与人民币金额 → 去重 → 至少三条才计算中位数 → 用户选择是否采用。

每条网络样本保存来源链接、网页标题、价格证据原句和页面日期（如果搜索结果提供）；查询时间与页面日期分别处理。未取得可靠样本就返回空结果，不能自行编造市场价。网页报价不等于成交价，模型对型号和成色的判断仍需要用户查看原页面。

需要在已经具备鉴权和配额的后端环境中配置 `TAVILY_API_KEY` 以及 Qwen 模型服务，再设置前端 `VITE_AI_ENDPOINT` 到实际后端地址。GitHub Pages 不能运行 Python 服务，任何密钥都不能进入前端仓库。没有配置时返回 503，界面明确提示，保留用户已经填写的价格。

参考官方接口：[Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)。联网接入采用官方 POST 接口；不绕过闲鱼、淘宝或其他平台登录与访问限制。尚未做真实联网价格检索评测，不声称已覆盖这些平台全部在售商品。

## 验证

回归覆盖数字格式、原价与报价区分、样本去重、少样本不推荐，以及拒绝无原文证据／金额不一致／外币样本。浏览器验证“台灯，我想卖10元”即时提示和确认页报价均为 10，打开参考价不会覆盖该值。

后续网站改动均需同步到原 GitHub 仓库并核验 Pages 部署成功。
